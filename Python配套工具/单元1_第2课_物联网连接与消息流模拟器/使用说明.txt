==============================================
 物联网连接与消息流模拟器 · 使用说明
==============================================
配套教材:清华大学出版社《信息科技》五年级下册
          第1单元 第2课《智能穿戴设备与物联网——物物相联的实现过程》(教材 P12—20)
适用对象:小学五年级学生与信息科技教师
运行环境:Windows 7/10/11,安装 Python 3.8 及以上(自带 Tkinter),
          完全离线运行,不需要联网,不需要安装任何第三方库。

----------------------------------------------
一、这个工具是做什么的?
----------------------------------------------
它在电脑上模拟一块"智能手表"把运动数据送上物联网的完整过程。
每一条心率/步数数据都要沿着六个节点旅行:

    人体数据 → 传感器 → 智能手表 → 无线网络 → 物联网平台 → 家人手机
              (采集)   (打包)     (发送)     (存储)       (推送)

你能亲眼看到数据包小圆点一跳一跳地移动,每一跳上方标注着
当前动作。工具里还能做两个关键实验:
  ① 把手表切成"离线(飞行模式)",看数据滞留在手表的
     「待同步队列」里;恢复联网后,看它们自动补传;
  ② 把信号强度调得很低,看数据包走得变慢、半路丢失,
     丢失的数据又自动放回队列重发。

这正好对应教材里物联网的四层体系架构:
  传感器 = 感知控制层;智能手表和无线网络 = 数据传输层;
  物联网平台 = 数据处理层;家人手机 = 应用决策层。

注意:工具里的心率、步数全部是电脑虚拟生成的,
不采集任何真实的人体健康信息。

----------------------------------------------
二、运行方法
----------------------------------------------
方法1(推荐,双击运行):
  1. 确认电脑已安装 Python(见"常见问题"第1条);
  2. 双击「物联网连接与消息流模拟器.py」即可打开窗口。
     若双击打开的是记事本,请右键该文件 → 打开方式 →
     选择「Python」(或 Python Launcher)。

方法2(命令行运行):
  1. 按 Win + R,输入 cmd,回车打开命令提示符;
  2. 输入(注意路径里有中文,建议直接把文件拖进命令行窗口):
         python "物联网连接与消息流模拟器.py"
     若提示找不到 python,可尝试输入 py 代替 python。

----------------------------------------------
三、界面分区说明
----------------------------------------------
① 场景区(左上)
   - 虚拟手表表盘:显示模拟时间、实时心率(心形图标会跳动)、
     累计步数、联网状态灯(绿=已联网,红=离线);
   - 待同步队列:手表旁边的一摞黄色小方块,就是还没送出去的
     数据,数字越大说明积压越多;
   - 信号条:五格信号,离线时一格都没有;
   - 物联网链路:六个节点方框排成一行,数据包小圆点沿虚线
     逐跳移动。蓝色圆点=采集中的数据(人体→手表),
     橙色圆点=同步中的数据(手表→手机),红色=丢失,
     绿色=已送达。圆点旁的小字是当前动作和数据编号,
     信号弱时还会标注「(慢)」;
   - 状态灯:每个节点右上角的小圆灯,绿=正常,橙=有积压或
     信号弱,红=离线,灰=待命(收不到数据);
   - 节点下方的彩色横线标注了教材的四层体系架构。

② 参数区(右上):3 个滑块 + 1 个联网开关,调整立即生效
   (含义见第五节)。

③ 运行控制区(右中):开始 / 暂停 / 单步 / 重置。

④ 状态与日志区(下方):
   - 状态栏:模拟时间(1周期=模拟1秒)、最新心率、累计步数、
     在线/离线状态、待同步队列数、信号强度;
   - 滚动日志:自动记录每一次采集、同步、丢包、补传和调参,
     不同类型用不同颜色显示。

⑤ 结果区(右下):
   - 统计:已采集条数 / 已同步条数 / 丢包次数(重发次数)/
     待同步条数;
   - 四个按钮:导出日志CSV / 导出小结TXT / 导入场景JSON / 帮助。

----------------------------------------------
四、每个按钮的作用
----------------------------------------------
▶ 开始         让模拟时间流动,每 0.5 秒推进一个周期(模拟1秒)。
⏸ 暂停         暂停时间流动,所有状态保持不变。
⏭ 单步         先暂停,再只推进一个周期。想看清一条数据怎么
               一跳一跳走完"采集→打包→发送→存储→推送",
               就连续点它。
🔄 重置         回到初始状态:时钟归零、队列清空、统计清零。
               参数滑块和日志保留,方便对比实验。
联网开关       勾选=手表联网;取消勾选=离线(飞行模式)。
               这是本课最重要的实验开关!
📥 导出日志CSV  把全部日志存成 CSV 表格(Excel 可直接打开),
               文件保存在本程序所在文件夹,文件名自动加时间戳。
📄 导出小结TXT  生成实验小结:参数、统计、数据旅程图、最近日志
               和思考题,可打印后手写完成,当作项目日志。
📂 导入场景JSON 读入「示例数据_模拟场景.json」,内含三组场景:
               教材示例 / 信号很差的地下室 / 离线飞行模式,
               选一组即可载入。
❓ 帮助         弹出快速帮助窗口。

----------------------------------------------
五、参数含义
----------------------------------------------
采样频率(每1~10秒采1次)
    传感器每隔几秒采集一次心率和步数。调小(如每1秒)数据
    又多又密,队列容易积压;调大(如每10秒)数据稀疏省流量。

网络信号强度(0%~100%)
    模拟手表所在位置的无线信号好坏:
      信号 ≥80%:数据包全速前进,基本不丢包;
      信号越弱:数据包每一跳要多等几个周期(走得慢),
                丢包率也越来越高(信号<20%时超过一半会丢)。
    丢失的数据会自动放回队列开头重发,不会真的消失。

运动强度(0~10档)
    0=静止(心率约70,步数不增加),3=散步,6=快走,
    8=跑步,10=冲刺(心率可到180左右)。观察手表表盘上
    心率和步数怎么跟着变化。

联网开关
    离线时:传感器照常采集,但数据只能留在手表的
    「待同步队列」;已出发但还没到平台的数据包也会退回队列。
    恢复联网后:队列里的数据按顺序自动补传,一条不丢。

----------------------------------------------
六、观察要点与建议实验(在线/离线对比)
----------------------------------------------
1. 完整旅程:点「开始」后盯住一个数据包,数一数它经过几个
   节点、每一跳的动作叫什么;再用「单步」慢速验证一遍。
2. 在线/离线对比(核心实验):
   先联网运行1分钟,记下"已同步"条数;点「重置」,取消勾选
   「联网」再运行同样时间——已同步始终是0,数据全部堆在
   待同步队列;重新勾选「联网」,看橙色数据包一条接一条补传,
   队列数字快速变小。想一想:离线时数据丢了吗?
3. 信号强弱对比:信号90%和信号15%各运行1分钟,比较丢包数、
   重发数和数据包移动速度(弱信号时圆点会标「(慢)」)。
4. 采样频率实验:每1秒采1次 vs 每10秒采1次,哪种队列更容易
   积压?哪种更省"流量"?
5. 运动强度实验:把强度从0拖到10,看心率是慢慢升上去的
   (不是瞬间跳变),这更接近真实身体的变化。
6. 导入三组示例场景逐一体验,实验后导出 CSV 和小结,
   完成教材"项目日志"。

----------------------------------------------
七、常见问题排查
----------------------------------------------
1. 双击 .py 文件没反应,或打开的是记事本?
   → 电脑可能没装 Python。到 python.org 下载安装包,安装时务必
     勾选 "Add Python to PATH",并保持默认勾选 tcl/tk 组件。
     已装 Python 的,右键文件 → 打开方式 → 选择 Python。

2. 提示 "No module named tkinter" 或 "_tkinter"?
   → 安装 Python 时没有安装 tcl/tk 组件。重新运行 Python 安装包,
     选择 Modify(修改),勾选 "tcl/tk and IDLE" 后完成安装。

3. 窗口打开了,但界面文字是方块或乱码?
   → 系统缺少中文字体。Windows 一般自带微软雅黑不会出现此问题;
     如出现,请在系统设置中确认已启用中文语言与字体。

4. 命令行运行提示 "python 不是内部或外部命令"?
   → Python 没有加入 PATH。可改用命令 py 运行,或重新安装
     Python 并勾选 "Add Python to PATH"。

5. 点了「开始」,家人手机一直收不到数据?
   → 依次检查:「联网」开关是不是没勾选(离线时数据都在队列里)?
     信号强度是不是调得很低(数据包变红丢失、反复重发)?
     日志区会写明每条数据到底去了哪里。

6. 待同步队列越来越长,正常吗?
   → 正常,这正是本课要观察的现象!离线或信号极差时数据送不
     出去,只能在手表里排队。恢复联网或调高信号后队列就会变短。
     如果想立刻清空,点「重置」。

7. 导出按钮点了,文件在哪里?
   → 在「物联网连接与消息流模拟器.py」所在的文件夹里,文件名
     形如"物联网消息流日志_20260724_153000.csv"。每次导出都
     生成新文件,不会覆盖旧文件。若程序放在只读位置(如光盘),
     请先把整个文件夹复制到桌面再运行。

8. 导入场景时提示"导入失败"?
   → 请确认选择的是本文件夹里的「示例数据_模拟场景.json」,
     且文件没有被改坏(可重新复制一份)。自己编写场景时,
     注意 JSON 里必须有「场景列表」数组。

9. 程序运行久了会不会卡?关窗口后会不会残留?
   → 不会。日志超过一定条数会自动滚动清理;关闭窗口时程序会
     正确停止所有定时任务,不会在后台残留进程。

----------------------------------------------

不采集、不联网、不上传任何真实信息;
