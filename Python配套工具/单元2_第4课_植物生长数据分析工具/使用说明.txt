==================================================
 植物生长数据采集与分析工具 · 使用说明
==================================================
配套教材:清华大学出版社《信息科技》五年级下册
          第2单元 第4课《植物生长日志——数据采集》(教材 P71—78)

本工具模拟"给植物做生长日志"的完整过程:
定时采集温度/湿度/光照/株高 → 表格查看 → 找出缺失和异常数据 →
逐条清洗 → 画折线图看生长趋势 → 统计并导出分析报告。
全程离线运行,数据仅存本机,不上传网络。

--------------------------------------------------
一、运行方法
--------------------------------------------------
1. 电脑上需要安装 Python 3(建议 3.8 及以上,安装时勾选 Add to PATH)。
   本工具只用 Python 自带的标准库,不需要安装任何第三方库。
2. 双击「植物生长数据分析工具.py」即可运行;
   如果双击打开的是记事本,请右键 → 打开方式 → 选择 Python。
3. 也可以在命令行运行:
   python 植物生长数据分析工具.py
4. 同文件夹中的「示例数据_植物生长记录.csv」是练习用示例数据,
   请保留在原位,方便在程序里一键找到并导入。

--------------------------------------------------
二、界面分区
--------------------------------------------------
① 数据区(左上)
   表格显示每一条采集记录:序号、日期、时间、温度、湿度、光照、株高、状态。
   行颜色含义:
     红色 = 这一行有可疑(异常)数据      黄色 = 这一行有缺失数据
     灰色 = 已被你剔除                    橙色 = 已被你标记存疑
     绿色 = 已被你确认保留                白色 = 正常

② 采集模拟区(右上)
   用"虚拟传感器"继续往后采集数据,参数与按钮见第三节。

③ 图表区(左下)
   Canvas 手绘折线图:
   - 「指标」下拉:选温度/湿度/光照/株高中的一个画主折线;
   - 「叠加对比」下拉:再叠加第二个指标,右侧多出一条数值轴(双轴对比),
     第二条线是虚线,方便比较"温度升、湿度降"这类关系;
   - 「时间范围 起点/终点」两个滑块:只看某一段时间,拉近了细看;
   - 缺失数据处折线自动断开;异常数据画红叉;标记存疑画橙色空心三角。

④ 数据清洗区(右中)
   - 「找可疑数据」:一键扫描,把所有缺失和异常的记录列成候选清单;
   - 在清单里选中一条,下方反馈框会解释"它为什么可疑";
   - 三个处理按钮:
       ❌ 剔除     = 认定是坏数据,统计和图表都不再使用它;
       ⚠ 标记存疑 = 拿不准,先留着用,但表格变橙色、图上画橙色三角提醒;
       ✔ 保留     = 确认是真实情况(比如那天真的特别热),恢复为正常数据。
   - 每处理一条都有即时反馈,说明这样处理意味着什么。

⑤ 结果区(右下)
   - 统计:四个指标各自的 平均/最高/最低,总生长量,日均生长速度;
   - 「导出清洗后CSV」「导出分析报告TXT」「导入CSV」「帮助」四个按钮。

底部消息栏:随时显示程序在做什么、下一步建议做什么。

--------------------------------------------------
三、按钮与参数含义
--------------------------------------------------
【采集模拟区参数】
  采样间隔(1/2/6/12小时):虚拟传感器每隔几小时采一次。
      间隔越小 → 数据越密、一天内的变化看得越细,但记录条数也越多。
  传感器故障概率(0~30%):每采一条数据,有多大概率出故障。
      出故障时,某个指标会"缺失"(空白)或变成离谱值(如温度88℃)。
  模拟天数(1~30天):点「开始采集」后,本轮一共模拟采集多少天。

【运行控制按钮】
  ▶ 开始采集:按设定参数连续自动采集(每0.3秒左右出一条新数据)。
  ⏸ 暂停:停下来,数据保留,可以先去清洗或看图。
  ⏭ 单步:一次只采一条,适合仔细观察每条新数据。
  🔄 重置:清空全部数据、图表和清洗记录,模拟时钟归零(参数保持不变)。

【结果区按钮】
  📥 导出清洗后CSV:把数据存成新CSV文件;已剔除的行不写入,
      标记/保留/缺失情况写在"清洗备注"列。
  📄 导出分析报告TXT:生成一份完整分析报告,含数据概况、各指标统计、
      生长趋势、你的清洗操作记录和 5 道"我的发现"填空题。
  📂 导入CSV:打开一份植物生长记录CSV。程序只"读取"文件内容,
      处理的是内存中的副本,原文件绝对不会被修改或覆盖。
  ❓ 帮助:弹出快速帮助窗口。

  所有导出文件保存在本程序所在文件夹,文件名自动加时间戳
  (例如 清洗后_植物生长记录_20260724_153000.csv),不会覆盖旧文件。

--------------------------------------------------
四、示例数据说明(哪里有"坑")
--------------------------------------------------
「示例数据_植物生长记录.csv」是一份 14 天、每天 4 次(0点/6点/12点/18点)
共 56 条的生长日志,里面故意埋了 5 处问题,等你来找:

  1. 第3天 12:00  温度 = 88℃      —— 异常:植物早就"熟"了,传感器坏了;
  2. 第5天 06:00  湿度为空白       —— 缺失:这一次没采到湿度;
  3. 第7天 18:00  光照 = -50 lux   —— 异常:光照不可能是负数;
  4. 第9天 12:00  株高为空白       —— 缺失:这一天中午忘了量株高;
  5. 第11天 00:00 株高 = 2.5cm     —— 异常:前一天还有16.5cm,植物不会变矮!

导入后先别急着点按钮:看看表格里哪些行是黄色、哪些是红色,
和上面这张"坑位表"对一对,再动手清洗。

--------------------------------------------------
五、分析小任务建议(课堂/课后)
--------------------------------------------------
任务1 找坑高手:导入示例数据,不看说明书第四节,自己把5处问题全找出来,
       说说每一处"为什么可疑"。
任务2 清洗前后大对比:先记下清洗前的平均温度,把 88℃ 那条剔除后再看,
       平均温度变了多少?想一想:一条坏数据的"破坏力"有多大?
任务3 双轴侦探:图表区选"温度",叠加"湿度",观察一天之内两条线
       此起彼伏的规律,用一句话描述它们的关系。
任务4 生长曲线:把指标切换到"株高",拖动时间范围滑块看前7天和后7天,
       算一算日均生长速度是否一样。
任务5 采样间隔实验:重置后,分别用12小时和1小时间隔各模拟2天,
       对比两张温度折线图——哪张能看出"中午热、夜里凉"?为什么?
任务6 故障大作战:把故障概率调到30%,模拟3天,统计出现了多少缺失
       和异常,再全部清洗一遍,最后导出报告写下感受。

--------------------------------------------------
六、常见问题排查
--------------------------------------------------
问题1:双击 .py 文件没有反应,或者一个黑窗口一闪就没了。
  → 电脑可能没装 Python,或没关联好。先安装 Python 3(勾选 Add to PATH),
    再右键 → 打开方式 → Python;或在命令行里运行查看报错信息。

问题2:双击后打开的是记事本,满屏都是代码。
  → .py 被记事本关联了。右键文件 → 打开方式 → 选择 Python 并设为默认。

问题3:运行时提示 No module named 'tkinter'。
  → Windows 官方安装包自带 tkinter,重新安装 Python 时勾选
    「tcl/tk and IDLE」组件即可;个别精简版/系统自带 Python 需补装。

问题4:界面中文显示成方块或乱码。
  → 一般是系统缺少微软雅黑字体,程序会自动改用系统默认字体,不影响使用;
    确保文件保存为 UTF-8 编码(下载原文件即是,不要用记事本另存)。

问题5:导入CSV时提示"导入失败"。
  → 检查表头是否包含 日期、时间、温度、湿度、光照、株高 这些字样;
    文件应为 CSV 格式(逗号分隔),支持 UTF-8 或 GBK 编码;
    若是 Excel 文件(.xlsx),请先"另存为 CSV"再导入。

问题6:导出的 CSV 用 Excel 打开会乱码吗?
  → 不会。导出文件使用 utf-8-sig 编码,Excel 双击即可正确显示中文;
    如果仍乱码,试试用 Excel 的"数据 → 从文本/CSV"方式打开。

问题7:点「开始采集」后没有新数据出现。
  → 看看底部消息栏:若显示"本轮模拟采集完成",说明上一轮天数已采完,
    再点一次「开始采集」会开始新一轮;也可以点「单步」逐条采集。

问题8:找不到导出的文件在哪里。
  → 所有导出文件都在「植物生长数据分析工具.py」所在的文件夹里,
    文件名以"清洗后_植物生长记录_"或"植物生长分析报告_"开头,带时间戳。

问题9:不小心把好数据"剔除"了怎么办?
  → 已剔除的行只是变灰,数据还在表格里。重新「导入CSV」可完全恢复;
    模拟数据则可点「重置」后重新采集。原始CSV文件永远不会被修改。

--------------------------------------------------
七、写给老师
--------------------------------------------------
* 仅用 Python 标准库(tkinter/ttk/csv/random/statistics/math 等),
  折线图为 Canvas 手绘,无需安装 matplotlib 等第三方库。
* 模拟采集由 root.after() 定时驱动,未使用线程,关闭窗口时自动取消任务。
* 数据判定规则简单、可解释,适合课堂讨论:
  温度 0~45℃、湿度 0~100%、光照 0~100000lux、株高 0~200cm 之外为可疑;
  株高比之前矮 1cm 以上或一次猛增超 6cm 为可疑;空白为缺失。
* 统计特意"不自动剔除"可疑数据:学生不清洗,平均值就会被 88℃ 带歪,
  剔除后统计立刻变化——让学生亲眼看到数据清洗的价值。
* 不需要管理员权限,不修改系统配置,不在后台常驻,不联网。
