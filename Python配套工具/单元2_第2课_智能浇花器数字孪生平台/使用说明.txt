==============================================
 智能浇花器数字孪生平台 · 使用说明
==============================================
配套教材:清华大学出版社《信息科技》五年级下册
          第2单元 第2课《物联网浇花器的实现——远程控制系统》(教材 P49—61)
适用对象:小学五年级学生与信息科技教师
运行环境:Windows 7/10/11,安装 Python 3.8 及以上(自带 Tkinter),
          完全离线运行,不需要联网,不需要安装任何第三方库。

----------------------------------------------
一、这个工具是做什么的?
----------------------------------------------
它在电脑上模拟一个"物联网浇花器"的数字孪生:
左边是虚拟花盆(植物会随土壤湿度改变颜色和姿态)和水箱,
下面是消息传输通道——远程浇水指令要经过
    手机 → 网络 → 物联网平台 → 控制器 → 水泵
五个节点逐跳传输,你能亲眼看到小圆点一站一站地移动。
你还可以制造网络延迟、丢包、断网,体验真实物联网会遇到的问题,
并设计自动浇水规则,让植物自己保持健康。

----------------------------------------------
二、运行方法
----------------------------------------------
方法1(推荐,双击运行):
  1. 确认电脑已安装 Python(见"常见问题"第1条);
  2. 双击「智能浇花器数字孪生平台.py」即可打开窗口。
     若双击打开的是记事本,请右键该文件 → 打开方式 →
     选择「Python」(或 Python Launcher)。

方法2(命令行运行):
  1. 按 Win + R,输入 cmd,回车打开命令提示符;
  2. 输入(注意路径里有中文,建议直接把文件拖进命令行窗口):
         python "智能浇花器数字孪生平台.py"
     若提示找不到 python,可尝试输入 py 代替 python。

----------------------------------------------
三、界面分区说明
----------------------------------------------
① 场景区(左上)
   - 花盆:盆里的蓝色水位就是土壤湿度;
   - 植物:湿度 40%~70% 时开红花最健康;低于 40% 发黄弯腰;
     低于 20% 枯萎倒伏;高于 85% 发紫,有烂根风险;
   - 水箱:右侧竖柱,蓝色液位是剩余水量,浇水会消耗它;
   - 消息通道:五个节点方框。橙色圆点=下行指令(手机→水泵),
     绿色圆点=上行湿度数据(传感器→手机),灰色=断网排队中,
     红色=丢失或过期。圆点上方的小字是消息内容。

② 参数区(右上):6 个滑块 + 2 个开关,拖动立即生效(含义见第五节)。

③ 运行控制区(右中):开始 / 暂停 / 单步 / 重置 / 手动浇水 / 断网切换。

④ 状态与日志区(下方):
   - 状态栏:模拟时钟(1周期=模拟10分钟)、当前湿度、水箱、
     今日浇水次数、冷却剩余、网络与水泵状态;
   - 滚动日志:自动记录每条指令、每次浇水、每个安全事件,
     不同类型用不同颜色显示。

⑤ 结果区(右下):
   - 统计:累计浇水次数、发送消息总数、丢失/过期消息数、平均土壤湿度;
   - 四个按钮:导出日志CSV / 导出报告TXT / 导入示例参数 / 帮助。

----------------------------------------------
四、每个按钮的作用
----------------------------------------------
▶ 开始        让模拟时间流动,每 0.6 秒推进一个周期(模拟10分钟)。
⏸ 暂停        暂停时间流动,所有状态保持不变。
⏭ 单步        先暂停,再只推进一个周期。想看清指令怎么一跳一跳
              走,就连续点它。
🔄 重置        回到初始状态:湿度50%、水箱100%、统计清零。
              参数滑块和日志保留,方便对比实验。
📱 手动浇水    模拟你在手机上点"浇水":发出一条下行指令,指令走完
              全部五个节点后水泵才开始工作。
🔌 断开网络    切换断网/联网。断网时消息会变灰排队;恢复网络后继续
              发送,但排队超过模拟3小时的指令会被判"过期"拒绝执行。
📥 导出日志CSV 把全部日志存成 CSV 表格(Excel 可直接打开),
              文件保存在本程序所在文件夹,文件名自动加时间戳。
📄 导出报告TXT 生成实验报告:参数、统计、最近日志和思考题,
              可打印后手写完成,当作项目日志。
📂 导入示例参数 读入「示例数据_浇花器参数.json」,内含三组配置:
              教材示例 / 省水模式 / 干旱挑战,选一组即可载入。
❓ 帮助        弹出快速帮助窗口。
自动浇水模式  勾选后控制器按规则自动浇水,不用点手动按钮。
防重复保护    勾选后,短时间内内容相同的重复指令只执行一次,
              防止"手抖连点两次"浇两次水。

----------------------------------------------
五、参数含义
----------------------------------------------
湿度阈值(15%~60%)   土壤湿度低于该值时触发自动浇水。调太高会频繁
                      浇水费水,调太低植物会先干渴。
每次浇水时长(10~60分钟) 浇得越久湿度涨得越多(每10分钟约+8%),
                      水箱也消耗越快(每10分钟约-3%)。
冷却时间(30~240分钟) 两次浇水之间的最小间隔,防止连续浇水淹坏植物。
每日安全上限(1~8次)  一天最多浇水次数。就算传感器坏了、指令重复,
                      也不会无限浇水——这是安全底线。
网络延迟(0~3档)      消息每走一跳额外等待的周期数。0=网络正常,
                      3=严重延迟,远程控制会变得很"迟钝"。
丢包率(0%~80%)       消息经过"网络段"(手机↔网络↔平台)时丢失的
                      概率。丢失的消息接收方永远收不到。

自动浇水规则(和教材一致):
    当 湿度 < 阈值 且 冷却已结束 且 今日浇水次数 < 每日上限
    时,控制器自动开泵浇一次水。

----------------------------------------------
六、建议的课堂实验
----------------------------------------------
1. 点「手动浇水」,用「单步」看指令逐跳走到水泵;
2. 导入「教材示例」,开自动模式,让植物连续几天保持健康;
3. 把丢包率调到 40%,连点几次手动浇水,数数丢了几条;
4. 点「断开网络」再发指令,马上恢复 vs 等很久再恢复,对比结果;
5. 关闭「防重复保护」,快速连点两次手动浇水,再打开保护对比;
6. 导入「省水模式」和「干旱挑战」,比较不同参数的效果;
7. 实验结束导出 CSV 和报告,完成教材"项目日志"。

----------------------------------------------
七、常见问题排查
----------------------------------------------
1. 双击 .py 文件没反应,或打开的是记事本?
   → 电脑可能没装 Python。到 python.org 下载安装包,安装时务必勾选
     "Add Python to PATH",并保持默认勾选 tcl/tk 组件(Tkinter)。
     已装 Python 的,右键文件 → 打开方式 → 选择 Python。

2. 提示 "No module named tkinter" 或 "_tkinter"?
   → 安装 Python 时没有安装 tcl/tk 组件。重新运行 Python 安装包,
     选择 Modify(修改),勾选 "tcl/tk and IDLE" 后完成安装。

3. 窗口打开了,但界面文字是方块或乱码?
   → 系统缺少中文字体。Windows 一般自带微软雅黑不会出现此问题;
     如出现,请在系统设置中确认已启用中文语言与字体。

4. 命令行运行提示 "python 不是内部或外部命令"?
   → Python 没有加入 PATH。可改用命令 py 运行,或重新安装 Python
     并勾选 "Add Python to PATH"。

5. 点了「手动浇水」,水泵一直没反应?
   → 依次检查:是不是没点「开始」(时间不流动,消息不会走)?
     是不是断网了(圆点变灰在排队)?丢包率是不是调得很高(圆点变
     红丢失)?是否在冷却中或已达每日上限(日志里会写"拒绝浇水")?

6. 导出按钮点了,文件在哪里?
   → 在「智能浇花器数字孪生平台.py」所在的文件夹里,文件名形如
     "浇花器日志_20260724_153000.csv"。每次导出都生成新文件,
     不会覆盖旧文件。若程序放在只读位置(如光盘),请先把整个
     文件夹复制到桌面再运行。

7. 导入示例参数时提示"导入失败"?
   → 请确认选择的是本文件夹里的「示例数据_浇花器参数.json」,
     且文件没有被改坏(可重新复制一份)。自己编写配置时,注意
     JSON 里必须有「配置列表」数组。

8. 程序运行久了会不会卡?
   → 不会。日志超过一定条数会自动滚动清理;关闭窗口时程序会
     正确停止所有定时任务,不会在后台残留。

----------------------------------------------
